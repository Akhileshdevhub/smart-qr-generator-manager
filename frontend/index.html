Static vs dynamic QR codes

The core idea behind this project.

Static

Content baked into the image

The QR encodes the actual content directly — a URL, Wi-Fi credentials, a contact card. It works forever without a server, but changing the destination means printing a new code.

Dynamic

A short link you control

The QR encodes a redirect URL like /r/aB3xK9p. The server looks up the current destination, records the scan, and forwards the visitor. You can change where it points without reprinting the code.
